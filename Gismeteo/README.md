# Тест-кейсы: сайт Гисметео

Учебный проект по ручному тестированию веб-сайта [gismeteo.ru](https://www.gismeteo.ru). Репозиторий содержит тест-кейсы для основного функционала, поиска города и общие негативные сценарии.

> Проект учебный и не связан с владельцами сайта Гисметео.

## Объект тестирования

| Параметр | Значение |
|----------|----------|
| Сайт | gismeteo.ru |
| Функционал | Прогноз погоды, поиск города, геолокация, единицы измерения |
| Вид тестирования | Ручное, функциональное |
| Дата составления | 27.10.2026 |

## Окружение

Заполните перед прогоном:

| Параметр | Значение |
|----------|----------|
| ОС | _например, Windows 11_ |
| Браузер | _например, Chrome 130_ |
| Разрешение экрана | _например, 1920×1080_ |

## Легенда

**Приоритет:** High — критичная функциональность; Medium — важная; Low — второстепенная.

**Тип:** Positive — штатный сценарий; Negative — некорректные данные или действия; Boundary — граничные значения.

**Статус:** ⬜ Not run · ✅ Passed · ❌ Failed · ⛔ Blocked

## Соглашение об ID

- `TC-GEN-001` — основной функционал, `NTC-GEN-001` — общие негативные сценарии.
- `TC-SEARCH-001` — позитивные кейсы поиска города, `NTC-SEARCH-001` — негативные.

**Тип:** дополнительно используются Boundary (граничные значения) и Security (базовые проверки безопасности ввода).
