### TC-GEN-001. Поиск города по точному названию

**Приоритет:** High | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Главная страница открыта

**Шаги:**
1. Нажать на поле поиска.
2. Ввести «Москва».
3. Выбрать «Москва» из выпадающего списка.

**Ожидаемый результат:** открывается страница прогноза для Москвы, в заголовке указан выбранный город, отображается текущая температура.

**Фактический результат:** _заполнить при прогоне_

---

### TC-GEN-002. Автодополнение при частичном вводе

**Приоритет:** Medium | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Главная страница открыта

**Шаги:**
1. Ввести в поиск «Новос».

**Ожидаемый результат:** появляется список подсказок, содержащий «Новосибирск» и другие подходящие населённые пункты.

**Фактический результат:** _заполнить при прогоне_

### TC-GEN-003. Поиск несуществующего населённого пункта

**Приоритет:** Medium | **Тип:** Negative | **Статус:** ⬜ Not run

**Предусловия:**
- Главная страница открыта

**Шаги:**
1. Ввести «Ззззыыыккк».
2. Нажать Enter.

**Ожидаемый результат:** выводится сообщение о том, что ничего не найдено. Ошибок и «белого экрана» нет.

**Фактический результат:** _заполнить при прогоне_

### TC-GEN-004. Отображение основных параметров погоды на сегодня

**Приоритет:** High | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Открыта страница прогноза для любого города

**Шаги:**
1. Перейти на вкладку «Сегодня».
2. Проверить блок с данными.

**Ожидаемый результат:** для каждого периода суток отображаются температура, осадки, ветер (скорость и направление), давление и влажность. Нет пустых полей и значений вроде «NaN» или «undefined».

**Фактический результат:** _заполнить при прогоне_

---

### TC-GEN-005. Переключение периода прогноза

**Приоритет:** High | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Открыта страница прогноза для любого города

**Шаги:**
1. Поочерёдно нажать вкладки: «Завтра», «3 дня», «10 дней», «14 дней».

**Ожидаемый результат:** при каждом переключении страница загружается без ошибок, количество отображаемых дней соответствует выбранной вкладке, даты идут по порядку начиная с текущей.

**Фактический результат:** _заполнить при прогоне_

---

### TC-GEN-006. Смена единиц измерения

**Приоритет:** Medium | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Открыта страница прогноза, единицы по умолчанию (°C, м/с, мм рт. ст.)

**Шаги:**
1. Открыть настройки единиц измерения.
2. Выбрать °F, км/ч и гПа.
3. Применить настройки.
4. Обновить страницу.

**Ожидаемый результат:** все значения на странице пересчитаны и показаны в новых единицах (например, 0 °C отображается как 32 °F). После обновления страницы настройки сохраняются.

**Фактический результат:** _заполнить при прогоне_

---

### TC-GEN-007. Определение местоположения пользователя

**Приоритет:** Medium | **Тип:** Positive | **Статус:** ⬜ Not run

**Предусловия:**
- Браузер поддерживает геолокацию, доступ к ней разрешён

**Шаги:**
1. Открыть сайт в новой вкладке.
2. Нажать на определение местоположения (или разрешить доступ в запросе браузера).

**Ожидаемый результат:** сайт показывает прогноз для города, в котором находится пользователь.

**Фактический результат:** _заполнить при прогоне_
